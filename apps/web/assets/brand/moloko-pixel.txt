// Moloko Pixel — the heading font, drawn for moloko after the "moloko" lettering of the owner's logo
// (assets/brand/logo-source.jpg). scripts/make-font.py turns this file into app/fonts/MolokoPixel.woff2.
//
// One character = one design pixel = one unit of the logo's lettering ('#' ink, '.' blank).
// The em is 24 pixels: at 24 px (page titles) a design pixel is exactly one CSS pixel.
//   x-height 13 · capitals and ascenders 17 · descenders 3–5 · Ё Й reach 21 · strokes 4 pixels thick
//   outer corners of round letters are cut by a 2×2 step; stem ends stay square
//   three-storey letters use 3-pixel bars in lowercase (e, з, в…) and 4-3-4 in capitals (Е, З, В…)
//   every glyph gets 1 blank pixel on each side, so letters stand 2 pixels apart, as in the logo
//   m o l k are redrawn from the logo on this grid; every other glyph is drawn in their style
//
// "==" starts a glyph: its code point(s) as U+XXXX, then the character(s) for reading. One drawing may
// serve several code points (Latin A and Cyrillic А). All rows of a glyph are equally wide; blank
// columns at the edges count as width. A row of '-' marks the baseline: rows above it stand on the
// baseline, rows below it hang under it. Without a '-' row, the last row stands on the baseline.
// Lines starting with // are comments.
