# Moloko Island (macOS)

«Динамический остров» для MacBook: маленькое нативное приложение, которое живёт у выреза
(«чёлки») экрана и показывает компактный вид moloko — страницу `/island` вашего сервера:
офис агентов, одобрения действий, перетаскивание сохранённых агентов в офис.

- **Свёрнут** — чёрная «таблетка» вокруг выреза: зелёная точка — агенты работают, серая —
  отдыхают, серое кольцо — нет связи или вы не вошли; янтарный значок — сколько действий ждут
  одобрения. На экранах без выреза — небольшая таблетка вверху по центру.
- **Подсказка** — когда одобрений становится больше, таблетка ненадолго подрастает и пишет,
  сколько действий ждут.
- **Развёрнут** — наведите указатель (или щёлкните): остров раскрывается в панель ~820×640
  со страницей moloko. Сворачивается, если увести указатель на секунду, по Esc или по щелчку
  мимо — если панель не закреплена (кнопка-булавка в шапке).
- **⌥Пробел** (из любого приложения) — остров раскрывается с курсором в строке задачи;
  Esc или ⌥Пробел ещё раз — сворачивается, клавиатура возвращается в прежнее приложение.
- **Уведомления об одобрениях** — когда агент ждёт одобрения, приходит уведомление macOS
  с кнопками «Одобрить» и «Отклонить»; щелчок по самому уведомлению открывает остров.
- **Правый щелчок** по таблетке или шапке: Обновить, Сменить адрес moloko…,
  Закрепить/Открепить, Горячая клавиша ▸, Запускать при входе, Выйти (и пункт про
  уведомления, если они не разрешены).

Иконки в Dock нет. Остров виден на всех рабочих столах и поверх полноэкранных приложений.

## Сборка

Нужны macOS 14+ и Command Line Tools (`xcode-select --install`); Xcode не нужен.

```sh
apps/mac-island/scripts/bundle.sh
```

Скрипт собирает `swift build -c release`, складывает `apps/mac-island/build/Moloko Island.app`
(иконка — из `apps/web/public/icons/icon-512.png`) и подписывает его ad-hoc.
Версию можно задать: `VERSION=0.2.0 BUILD_NUMBER=2 apps/mac-island/scripts/bundle.sh`.

## Установка

1. Перетащите `apps/mac-island/build/Moloko Island.app` в «Программы» (`/Applications`).
2. Запустите. Если приложение собрано на этом же Mac — откроется сразу.
   Если его скопировали с другого компьютера (оно не нотаризовано): правый щелчок → «Открыть»;
   на macOS 15 и новее — «Системные настройки → Конфиденциальность и безопасность →
   Всё равно открыть» (или `xattr -dr com.apple.quarantine "/Applications/Moloko Island.app"`).
3. При первом запуске появится окно «Адрес moloko» — введите адрес вашего сервера,
   например `https://имя.ts.net` (принимаются только http/https; путь после адреса отбрасывается).
4. Наведите на остров и войдите в moloko прямо в нём — вход запоминается (обычные cookie).
5. Автозапуск: правый щелчок → «Запускать при входе» (включайте, когда приложение уже лежит
   в «Программах»).

Сменить адрес: правый щелчок → «Сменить адрес moloko…». Адрес хранится в
`defaults read kz.moloko.island serverURL`.

## Горячая клавиша

По умолчанию **⌥Пробел** (Option + Пробел): остров раскрывается, получает клавиатуру и ставит
курсор в строку задачи. Открытый так остров не сворачивается, когда указатель далеко, — только
по Esc, по горячей клавише ещё раз, по кнопке «Свернуть» или по щелчку мимо. После Esc
клавиатура возвращается в приложение, где вы были.

Сменить: правый щелчок → «Горячая клавиша» → ⌥Пробел, ⌃⌥Пробел, ⇧⌘Пробел, ⌃⇧Пробел или
«Выключить». Выбор хранится в `defaults read kz.moloko.island hotKey`.

- Разрешение «Универсальный доступ» не нужно: клавиша регистрируется через Carbon
  `RegisterEventHotKey` — система присылает приложению только это сочетание.
- Если сочетание занято другим приложением (оно тоже зарегистрировало его как исключительное),
  остров скажет об этом: при выборе в меню — окном, прежнее сочетание остаётся; при запуске —
  окном с кнопкой «Выключить горячую клавишу», а в меню будет «— занята».
- Сочетания, которые занимает сама macOS (Системные настройки → Клавиатура → Сочетания клавиш;
  например, ⌃⌥Пробел — «следующий источник ввода», если включено), в меню помечены
  «— занято macOS» и недоступны.
- Приложения, которые перехватывают клавиатуру иначе (не через `RegisterEventHotKey`), заметить
  нельзя: если ⌥Пробел ничего не делает, выберите другое сочетание.
- Пока горячая клавиша — ⌥Пробел, этим сочетанием нельзя напечатать неразрывный пробел.

## Уведомления об одобрениях

Когда действие агента ждёт одобрения, остров показывает уведомление macOS: «moloko: нужно
одобрение», кто просит и что именно он хочет сделать, кнопки **«Одобрить»** и **«Отклонить»**.
Ответ выполняет страница `/island` внутри острова (у неё ваш вход в moloko и CSRF): нажали
кнопку — уведомление исчезает; если moloko не принял ответ (например, на запрос уже ответили
в другом месте) или не ответил за 30 секунд, придёт уведомление «Не удалось одобрить/отклонить»
с причиной. Щелчок по уведомлению открывает остров. Отменить задачу целиком можно только в
острове или на сайте.

- Разрешение спрашивается при первом запросе на одобрение, а не при запуске. Если вы его
  запретили, в меню острова появится «Уведомления об одобрениях запрещены — открыть Настройки…»
  (Системные настройки → Уведомления → Moloko Island). Пока остров ни разу не спрашивал — пункт
  «Включить уведомления об одобрениях».
- Стиль по умолчанию — «Предупреждения»: уведомление остаётся на экране, пока вы не ответите.
  Можно переключить на «Баннеры» в тех же настройках.
- Каждый запрос показывается один раз; уведомления о запросах, на которые ответили в другом
  месте (на сайте, с телефона) или которые истекли, остров убирает сам.
- Сборка с подписью ad-hoc уведомления показывает, но приложение должно быть запущено через
  Finder, `open` или автозапуск (LaunchServices): при запуске бинарника из `Contents/MacOS`
  в терминале macOS отказывает в уведомлениях («Failed to find or validate client»).
- Без Developer ID (подписи разработчика Apple) недоступны «срочные» уведомления
  (time-sensitive), которые пробиваются через режим «Фокусирование»: в режиме «Не беспокоить»
  запросы на одобрение копятся в Центре уведомлений.

## Как остров разговаривает со страницей `/island`

Страница → приложение (`window.webkit.messageHandlers.molokoIsland.postMessage(...)`):

| Сообщение | Что делает |
|---|---|
| `{ type: "status", pendingApprovals: number, activeAgents: number, signedIn: boolean }` | обновляет таблетку; рост `pendingApprovals` в свёрнутом виде → подсказка |
| `{ type: "openExternal", url: string }` | открывает ссылку в браузере по умолчанию (http/https/mailto) |
| `{ type: "collapse" }` | сворачивает остров (и снимает закрепление) |
| `{ type: "approval", id, summary, agent }` | новый запрос на одобрение (и каждый ждущий — один раз после загрузки страницы) → уведомление; повтор того же `id` игнорируется |
| `{ type: "approvalGone", id }` | запрос больше не ждёт (ответили где угодно, истёк, задачу отменили) → уведомление убирается |
| `{ type: "approvalsPending", ids }` | один раз после загрузки страницы: все ждущие `id` → убираются уведомления о прочих (ответили, пока страницы не было) |
| `{ type: "approvalResolved", id, ok, message }` | ответ на действие `action` (см. ниже); `ok: false` → уведомление «Не удалось…» с `message` |

Приложение → страница:

- `window.molokoIsland = { native: true, version, open }` — есть с самого начала загрузки;
- `window.dispatchEvent(new CustomEvent("moloko-island", { detail }))`, где `detail`:
  - `{ open }` — при каждом раскрытии/сворачивании и один раз после загрузки страницы;
  - `{ open: true, focus: "task" }` — раскрыт горячей клавишей: курсор в строку задачи;
  - `{ action: "approve" | "reject", approvalId }` — нажата кнопка в уведомлении: страница
    вызывает `POST /approvals/{id}/approve|reject` и отвечает `approvalResolved`.

Код страницы: `apps/web/features/island/bridge.ts` (контракт), `island-bridge.tsx`.

Сообщения принимаются только от главного фрейма сервера moloko. Пока остров свёрнут, страница
скрыта (`document.visibilityState === "hidden"`, без отрисовки), но жива и держит соединение.
Ссылки, уходящие с `/island` и `/login` (и `target="_blank"`), открываются в браузере;
`/login?next=/island` и `/island…` остаются внутри.

## Отладка

- Веб-инспектор: Safari → «Разработка» → «Moloko Island».
- Журнал: `/usr/bin/log show --last 10m --predicate 'subsystem == "kz.moloko.island"'`
  (в zsh просто `log` — встроенная команда оболочки).
- Другой сервер на один запуск, без сохранения:
  `open --env MOLOKO_ISLAND_SERVER=http://127.0.0.1:3000 "apps/mac-island/build/Moloko Island.app"`.
- Тестовая сборка рядом с установленной (свои настройки, cookie и разрешение на уведомления):
  `BUNDLE_ID=kz.moloko.island.dev apps/mac-island/scripts/bundle.sh`.
- `MOLOKO_ISLAND_DEBUG=1` дублирует журнал в stdout и включает команды через distributed
  notification `kz.moloko.island.debug` (expand, collapse, peek, pin, unpin, escape, state,
  probe, snapshot:<путь>, hotkey, hotkey-preset:<id>, menu, shortcuts, notifications,
  notify-provisional, clear-notifications, respond:<approve|reject|open>:<id>) — см.
  `Sources/MolokoIsland/DebugCommands.swift`. Запускайте через `open`, чтобы работали
  уведомления: `open --stdout /tmp/island.log --env MOLOKO_ISLAND_DEBUG=1 "apps/mac-island/build/Moloko Island.app"`.

## Островок прямо в вырезе

Островок встаёт в вырез экрана MacBook, если вырез входит в изображение. У MacBook с вырезом есть режимы экрана «под вырезом» (например, 1512×945 рядом со стандартным 1512×982): в них полоса с вырезом погашена, меню опускается ниже, и рисовать там не может ни одно приложение — тогда островок висит пилюлей сверху по центру.

Чтобы вернуть вырез: правый клик по островку → «Показать вырез (экран …)» — пункт появляется только в таком режиме и переключает экран на режим того же масштаба с вырезом. Или «Системные настройки → Дисплеи» → вариант по умолчанию.
