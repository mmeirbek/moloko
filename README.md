# 🏢 Peter — виртуальный офис ИИ-агентов

Личная команда ИИ-агентов, которая живёт на сервере и работает 24/7. Вы управляете ею с телефона через сайт, ноутбук не нужен.

- **Офис** — экран, где видно, кто из сотрудников свободен, кто работает и над чем, а кто ждёт вашего ответа.
- **Чат** — отправляете задачу менеджеру (или сразу нужному сотруднику), а в ленте видно ход работы.
- **Задачи** — все поручения с подзадачами, ходом работы, результатом, расходами и кнопкой «Стоп».
- **Диск** — общий диск офиса: агенты сохраняют туда отчёты, тексты и код. Это же их общая память.
- **Команда** — нанимайте, настраивайте и увольняйте сотрудников: имя, роль, инструкции, модель, доступ в интернет.

Сайт можно установить на телефон как приложение: в браузере «Поделиться → На экран „Домой“» на iPhone или «Установить приложение» на Android.

## Как это устроено

```
Телефон (браузер / PWA)
   │  HTTPS: команды, ответы на вопросы
   │  SSE: живые обновления офиса
   ▼
Сервер на Node.js (Express)  ─── SQLite (/data/office.db): агенты, задачи, лента, файлы
   │
   ▼
Claude API: у каждого агента свой цикл с инструментами
```

Стартовая команда:

| Сотрудник | Роль | Что умеет |
|---|---|---|
| 🧑‍💼 Пётр | Менеджер | Принимает задачи, раздаёт их коллегам (параллельно), собирает итог |
| 🔎 Аня | Исследователь | Поиск и чтение сайтов в интернете |
| 👨‍💻 Макс | Разработчик | Код, скрипты, технические планы, тоже ходит в интернет |
| ✍️ Лера | Копирайтер | Посты, тексты, контент-планы |

Инструменты агентов:

- `delegate_task` — поручить задачу коллеге и дождаться результата. Есть только у тех, кто «раздаёт задачи», и только в задачах верхнего уровня, чтобы агенты не гоняли задачи друг другу по кругу.
- `ask_boss` — задать вам вопрос. На телефоне появится жёлтая карточка, задача ждёт, пока вы не ответите.
- `write_file`, `read_file`, `list_files` — общий диск офиса.
- `web_search`, `web_fetch` — поиск и чтение страниц (серверные инструменты Claude), если у агента включён интернет.

Защита от сюрпризов в счёте: суточный лимит расходов (`DAILY_BUDGET_USD`), лимит шагов на задачу (`MAX_TURNS`), ограничение параллельных запросов (`MAX_PARALLEL`). Расходы считаются приблизительно по прайсу и видны в шапке и у каждой задачи.

## Запуск на компьютере

Нужен Node.js 22.13 или новее.

```bash
npm install
cp .env.example .env        # впишите ANTHROPIC_API_KEY
export $(grep -v '^#' .env | xargs)
npm run dev                 # http://localhost:3000, пароль по умолчанию: dev
```

## Деплой (чтобы офис работал без ноутбука)

Агенты работают долго (минуты), а им нужны фоновые процессы и постоянный диск, поэтому **Vercel и Netlify не подходят**. Нужен обычный постоянно работающий сервер с диском. Проще всего так:

### Вариант A: Railway (самый простой)

1. [railway.com](https://railway.com) → New Project → Deploy from GitHub repo → выберите этот репозиторий. Railway сам найдёт `Dockerfile`.
2. В сервисе: **Settings → Volumes → Add Volume**, путь монтирования `/data`.
3. **Variables**: `ANTHROPIC_API_KEY`, `APP_PASSWORD`, `SESSION_SECRET` (любая длинная случайная строка).
4. **Settings → Networking → Generate Domain**. Откройте этот адрес на телефоне и войдите.

### Вариант B: Render

New → Blueprint → выберите репозиторий: `render.yaml` уже настроен (Docker, диск `/data`, проверка здоровья). Останется ввести `ANTHROPIC_API_KEY` и `APP_PASSWORD`. Постоянный диск у Render есть только на платном плане.

### Вариант C: свой VPS

```bash
docker build -t peter-office .
docker run -d --restart unless-stopped -p 3000:3000 -v office-data:/data \
  -e ANTHROPIC_API_KEY=... -e APP_PASSWORD=... -e SESSION_SECRET=... peter-office
```

Перед сервером поставьте HTTPS, например Caddy: `caddy reverse-proxy --from office.example.com --to :3000`.

## Настройки

Все переменные с пояснениями собраны в [`.env.example`](.env.example). Главные:

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | Ключ Claude API |
| `APP_PASSWORD` | `dev` (в продакшене обязателен) | Пароль для входа |
| `SESSION_SECRET` | случайный при старте | Подпись сессий: задайте, чтобы не входить заново после перезапуска |
| `MODEL` | `claude-opus-5-5` | Модель по умолчанию. Для экономии можно поставить `claude-sonnet-5-5` или `claude-haiku-5-5`, а у каждого агента выбрать свою |
| `DAILY_BUDGET_USD` | `10` | Суточный лимит расходов |

## Структура

```
src/
  server.ts          HTTP API, SSE, раздача фронтенда
  auth.ts            вход по паролю, cookie-сессия
  db.ts              SQLite-схема (встроенный node:sqlite, без нативных зависимостей)
  office.ts          операции с агентами, задачами, лентой, вопросами, файлами
  agents/
    defaults.ts      стартовая команда
    runner.ts        очередь задач и цикл агента (Claude API + инструменты)
    tools.ts         описания инструментов агентов
    pricing.ts       приблизительный расчёт стоимости
public/              фронтенд без сборки: index.html, app.js, style.css, PWA
```

## Что можно добавить дальше

- Push-уведомления на телефон, когда сайт закрыт (Web Push). Сейчас уведомления приходят, только пока вкладка открыта.
- Регулярные задачи («каждое утро собирай новости рынка»).
- Интеграции: Telegram-бот как второй пульт управления, GitHub, Google Docs, почта.
- Загрузка файлов и фото с телефона в задачу.
- Память агента между задачами (сейчас память — это общий диск и короткая история последних задач).
