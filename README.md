# 🏢 Peter — пиксельный офис субагентов

Личный офис ИИ-субагентов. Он живёт на сервере и работает 24/7, а управляете вы им с телефона через сайт. Ноутбук не нужен.

Офис разбит на **отделы**. В каждом отделе есть координатор и 2–4 узких специалиста-субагента. Когда вы даёте отделу задание, координатор делит его на части и раздаёт специалистам. Разные отделы работают одновременно над разными задачами.

## Ваши субагенты: `.claude/agents/`

Субагенты описаны в формате Claude Code: каждый — это markdown-файл с YAML-заголовком (`name`, `description`, `tools`, `model`) и системным промптом. Одни и те же файлы работают и в Claude Code (если открыть этот репозиторий), и в офисе: сервер читает их при каждом старте.

| Отдел | Агенты |
|---|---|
| 🔵 Учебный центр | `sat-trainer` — Digital SAT · `ielts-trainer` — IELTS |
| 🟢 Лаборатория кода | `code-reviewer` — ревью без изменений · `tester` — тесты и баг-репорты |
| 🟡 Штаб идей | `idea-critic` — критика идей и рынок · `digest` — еженедельный дайджест |

- **Добавили файл** — после перезапуска агент появится в офисе. Если его нет в раскладке `src/agents/defaults.ts`, он попадёт в отдел «Новые агенты».
- **Изменили файл** — офис подхватит новый промпт, инструменты и модель.
- **Удалили файл** — агент пропадёт из офиса.
- Отдел агента можно поменять в приложении. Сам промпт правится только в файле.
- Офис добавляет каждому агенту инструмент `ask_boss`, чтобы тот мог задать вам вопрос на телефон.
- **Bash в офисе по умолчанию выключен** (он есть у `code-reviewer` и `tester`): на сервере он выполнил бы любую команду. Включить его можно переменной `ALLOW_BASH=1`, если вы понимаете риск. Без Bash `tester` не сможет запускать тесты и честно об этом скажет. В Claude Code на вашем компьютере Bash работает как обычно.

## Что есть в приложении

- **Офис.** Здание из пиксельных комнат. Маленькие сотрудники отдыхают на диване. Получив поручение, сотрудник встаёт, идёт к столу и печатает, на мониторе бегут строки. С вопросом он поднимает руку, а сделав работу, получает ✓ и возвращается на диван. На доске в комнате видно, сколько поручений выполнено. Тап по человечку открывает его карточку.
- **Пульт.** Каждому отделу можно написать своё задание и запустить все разом. Черновики сохраняются.
- **Лента.** Всё, что происходит в офисе, с фильтром по отделам.
- **Диск.** Общая папка, куда субагенты кладут отчёты, тексты и код.
- **Отделы.** Подключение к Claude, модель по умолчанию, настройка команды.
- **Игровые элементы:** уровни отделов и офиса, серия дней подряд, конфетти по окончании задачи, уведомления.

Сайт ставится на телефон как приложение: «Поделиться → На экран „Домой“» на iPhone или «Установить приложение» на Android.

## Как устроено

```
Телефон (PWA)  ──HTTPS / SSE──▶  Node.js сервер (Express + SQLite)
                                   │  на каждую задачу отдела:
                                   ▼
                     Claude Agent SDK → Claude Code (координатор)
                                   ├─ субагент 1 ─┐
                                   ├─ субагент 2 ─┼─ параллельно
                                   └─ субагент 3 ─┘
                     инструменты: Read/Write/Edit (только диск офиса), WebSearch/WebFetch, ask_boss
```

- Движок — [Claude Agent SDK](https://code.claude.com/docs/en/agent-sdk/overview). Субагенты — это его встроенные `agents`, а координатор вызывает их инструментом `Agent`.
- `ask_boss` — свой инструмент: вопрос приходит вам на телефон, а задача ждёт ответа хоть несколько часов.
- Файловые инструменты ограничены папкой диска офиса через хук `PreToolUse`. Bash отключён.
- Одновременно работают до `MAX_PARALLEL` отделов. Внутри отдела задачи идут по очереди.

## Подключение к Claude

Нужен один из двух вариантов.

### Вариант 1. Подписка Claude Pro/Max

1. Один раз на любом компьютере выполните `npx @anthropic-ai/claude-code setup-token` и войдите своим аккаунтом. Вы получите токен на год.
2. На хостинге задайте переменную `CLAUDE_CODE_OAUTH_TOKEN`.

Работа субагентов тратит лимиты подписки: окно 5 часов и недельный лимит. Текущая загрузка видна в шапке приложения. На Pro лимиты небольшие, поэтому для простых отделов лучше выбрать Sonnet или Haiku.

> ⚠️ **Риск.** Anthropic пишет, что OAuth-вход подписки предназначен для «обычного использования Claude Code и других нативных приложений Anthropic», а разработчикам продуктов на Agent SDK следует использовать API-ключ. Прямого запрета на личное приложение для одного себя в документации нет, но и разрешения тоже. Поэтому используйте офис только сами, никому не давайте доступ и учитывайте, что аккаунт теоретически могут ограничить. Если хотите без риска, выбирайте вариант 2.

### Вариант 2. API-ключ

Создайте ключ на [platform.claude.com](https://platform.claude.com) и задайте `ANTHROPIC_API_KEY`. Оплата идёт по токенам и ограничена суточным лимитом `DAILY_BUDGET_USD`.

В подписках Max ($100 в месяц на Max 5x, $200 на Max 20x) и Team уже включены ежемесячные API-кредиты. Их привязывают в claude.ai → Settings → Billing → API credits, и тогда этот вариант по сути входит в подписку ([подробнее](https://support.claude.com/en/articles/17154008)).

## Запуск на компьютере

Нужен Node.js 22.13 или новее.

```bash
npm install
cp .env.example .env        # впишите токен или ключ
export $(grep -v '^#' .env | xargs)
npm run dev                 # http://localhost:3000, пароль по умолчанию: dev
```

## Деплой

Отделу нужен постоянно работающий процесс (Claude Code) и диск, поэтому **Vercel и Netlify не подходят**. Подходят обычные серверы с диском. Каждый работающий отдел — это отдельный процесс примерно на 300 МБ памяти, поэтому берите тариф с 1–2 ГБ.

- **Railway:** New Project → Deploy from GitHub → Volume с путём `/data` → переменные → Generate Domain.
- **Render:** New → Blueprint, готовый `render.yaml` уже в репозитории.
- **Свой VPS:**
  ```bash
  docker build -t peter-office .
  docker run -d --restart unless-stopped -p 3000:3000 -v office-data:/data \
    -e CLAUDE_CODE_OAUTH_TOKEN=... -e APP_PASSWORD=... -e SESSION_SECRET=... peter-office
  ```

## Структура

```
src/
  server.ts          HTTP API, SSE, раздача фронтенда
  auth.ts            вход по паролю
  db.ts              схема SQLite (встроенный node:sqlite)
  office.ts          отделы, субагенты, задачи, лента, вопросы
  drive.ts           диск офиса (папка DATA_DIR/drive)
  agents/
    files.ts         чтение .claude/agents/*.md
    defaults.ts      раскладка агентов по отделам
    runner.ts        очередь отделов и запуск Claude Agent SDK
    pricing.ts       список моделей
.claude/agents/      ваши субагенты (формат Claude Code)
public/
  sprites.js         пиксельная графика: комнаты, человечки, иконки (всё рисуется кодом)
  app.js, style.css  интерфейс без сборки
  fonts/             Handjet и Press Start 2P (SIL OFL)
```
